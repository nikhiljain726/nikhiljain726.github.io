Something I built

An open-source CRM MCP, built by a non-engineer

Proof that GTM tooling is buildable now, without writing code. It is a 53-tool server that gives any AI client full read-and-write access to a CRM, with dry-run previews and an audit log of every change. I built it on Pipedrive, but the shape works for any CRM. If you run Pipedrive, you can point it at yours in about two minutes.
