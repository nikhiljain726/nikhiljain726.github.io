The NBS agent that writes next actions into the CRM

AI & agent workflows  ·  Jun 2026  ·  3 min read

A pipeline review is mostly the same question asked forty times: what is the next best action on this deal, and is anyone doing it. I got tired of asking it by hand, so I built an agent to.

The NBS agent, for next best step, reads a deal the way a good manager would. It looks at the stage, the last activity, how long since anyone touched it, the open tasks, and the notes. Then it decides the single next best action and writes it straight into Pipedrive as a task on the deal, assigned to the owner, with a one-line reason.

The point is not advice in a chat window. It is a task in the rep's list, with a reason attached.

The guardrails are the same as everything else I build. It runs on a schedule, it logs what it created, and it writes tasks rather than silently changing deals, so a human is always the one who acts. A stale deal gets a nudge. A deal with no next activity gets one scheduled. A deal that has gone quiet for two weeks gets flagged for a person to look at.

It does not replace the pipeline review. It makes the review about the three deals that actually need a human, instead of the forty that just needed a reminder.
