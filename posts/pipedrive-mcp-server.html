I built a 53-tool Pipedrive MCP server, and I cannot write code

AI & agent workflows  ·  July 2026  ·  9 min read

I run growth at a retail media company. I am not an engineer. A few weeks ago I asked Claude a simple question: if I have my Pipedrive API key, can I build a connector that reads and writes my CRM from a chat window? The answer turned out to be yes, and the thing I ended up with is now 53 tools deep and running our actual sales pipeline. I am putting the whole server up for anyone to use. This is the story of how it got built, because the how is more useful than the code.

The first surprise was how little I needed to know. An MCP server is just a small program that hands a set of tools to Claude. Each tool wraps one thing the Pipedrive API can do: search a deal, create a contact, add a note. Claude does the wrapping. I described what I wanted, Claude wrote the Python, and I copied files where I was told to copy them. My one contribution on day one was noticing my Mac had an old version of Python and installing a new one.

It worked on the first real test. I asked it to list my pipelines and it read back all six, live, from Pipedrive. That moment matters more than it sounds. The gap between this might work and this is reading my real CRM is the gap most people never cross, and it took about fifteen minutes.

The tools came from problems, not from a plan

I did not sit down and design 53 tools. I started with maybe twenty, the obvious ones, and then every few days I hit a wall and added whatever the wall demanded.

I needed to clean up duplicate contacts, so we added merge tools. Then I had 3,196 duplicate people and no way to find them programmatically, so we added a duplicate finder. Then I learned Pipedrive's own find-duplicates screen matches on name alone, which flags three different people named the same at three different companies as one person. Merging those would corrupt data you cannot get back. So the finder got rebuilt to match the way a careful human would: same name plus a shared email, phone, or company, never name by itself.

Then I wanted to attach 984 sent emails to the right deals. New tools. Then I wanted to tag deals with which of our product modules they cover. New tools. Then I wanted tasks to land in the right person's task list instead of mine, which meant learning that Pipedrive's older API calls the assignee user_id while the newer one calls it owner_id, and the tool had to speak the right one. New behavior.

This is the part worth copying. Do not try to build the complete thing up front. Build the tool you need the hour you need it. The server grew in the exact shape of the work, which is why it fits the work.

The mistakes taught me the most

Two of them stand out.

The first was a bug in how the email tool searched. It reported that I had 2 unlinked emails when Pipedrive's own screen clearly showed 984. The tool was only ever opening the top drawer of the filing cabinet. It counted every email it scanned against its limit, but only kept the unlinked ones, so a folder full of already-linked emails used up the whole budget before it ever reached the backlog. Once you see it, it is obvious. Before you see it, you trust a number that is wrong. That is the dangerous kind of bug, the one that answers confidently.

The second was subtler and I nearly walked into it. I asked whether I could skip the native merge and just copy one record's fields onto another, then delete the loser. It sounds equivalent. It is not. When Pipedrive merges two records, it re-points all the deals, activities, and notes that were attached to the loser so they now point at the survivor, then deletes the loser. A copy-and-delete moves the visible fields but orphans all of that history. You would keep the name and email and quietly lose the three open deals. The lesson: when a platform gives you a real merge, the value is not in the fields you can see, it is in the links you cannot.

Safety stopped being optional

There is a point where a toy becomes a machine that can hurt you, and you can feel it happen. For me it was the moment I was about to run merges across thousands of real records with no human watching each one. Merges cannot be undone.

So before any of that ran, we added two things. Every tool that changes data now takes a dry_run flag that shows you exactly what it would do without doing it. And every real change appends a line to a local log: what changed, which record survived, which was deleted, when. Neither is clever. Both are the difference between a mistake you can trace and a mistake you cannot.

If you build one of these, add those two things before you point it at anything you care about, not after. The urge is to add them after the first scare. Add them before.

Then I moved it off my laptop

The whole thing ran on my Mac, which meant it only worked when my Mac was on. To fix that I put the code in a private GitHub repo and connected it to Claude Code on the web, which runs in the cloud. The credentials stay out of the code entirely. The repo holds the tools, and my Pipedrive key lives in a separate environment setting that never gets saved into the repo. Same key stays private, code can be shared.

That separation is the quiet unlock for a team. A colleague can use the exact same tools with their own Pipedrive key, so every action is attributed to the right person, and if they leave you revoke one key without touching yours.

What most connectors give you, and what this one does

Most general MCP connectors for a CRM expose a handful of read-only tools. You can look, not act. That is fine for answering a question and useless for running a pipeline. This server has 53 tools, and most of them write: create, update, merge, dedupe, bulk-edit, reassign, link email, tag products, manage custom fields, and read back an audit log of everything it changed. The whole point was to close the gap between a chat window and the work.

How to run it on a Mac

No coding needed. About fifteen minutes end to end.

  1. Install Python 3. Download it from python.org, or if you use Homebrew run brew install python. Check it worked: open Terminal and run python3 --version.
  2. Get the server file. Download server.py (embedded below, or from the GitHub repo) into a folder, for example ~/pipedrive-mcp.
  3. Install the three dependencies. In Terminal: pip3 install "mcp[cli]" httpx pydantic.
  4. Get your Pipedrive details. In Pipedrive, go to Settings, then Personal preferences, then API, and copy your API token. Your domain is the part before .pipedrive.com in your account URL.
  5. Point Claude Desktop at it. Open Claude Desktop settings, edit the developer config file, and add the block below with the full path to your server.py and your two values.
  6. Restart Claude Desktop and ask it to list your pipelines. If it reads them back, you are live.
In claude_desktop_config.json:

{ "mcpServers": { "pipedrive": { "command": "python3", "args": ["/full/path/to/server.py"], "env": { "PIPEDRIVE_API_TOKEN": "your-token", "PIPEDRIVE_DOMAIN": "yourcompany" } } } }

To run it in the cloud instead of your laptop, put the file in a private GitHub repo, set the same two values as environment variables (never in the code), and connect it to Claude Code on the web.

What I actually learned

You do not need to know how to code to build software anymore. You need to know what you want, be willing to test it against reality, and be honest about what can go wrong. I supplied the domain knowledge, the CRM, the actual problems, and the judgment about what was too risky to automate. The code was the easy part, which is a sentence I could not have written a month ago.

The server is open source, on GitHub at github.com/nikhiljain726/pipedrive-mcp. Take it, point it at your own Pipedrive, add the tools your own walls demand. If you are not an engineer, that is not a disqualification. It might even be the point.

"""
Pipedrive MCP Server
====================
A Model Context Protocol server that connects Claude to your Pipedrive CRM.
Supports reading and writing deals, contacts, organizations, activities, notes, and pipelines.
Includes merge tools for deduplicating persons, organizations, and deals.

Setup:
  1. pip install "mcp[cli]" httpx pydantic
  2. Set your env vars:
       export PIPEDRIVE_API_TOKEN="your-api-token-here"
       export PIPEDRIVE_DOMAIN="yourcompany"   (the part before .pipedrive.com)
  3. Run:  python server.py
"""

import os
import json
import httpx
from typing import Optional, List, Dict, Any
from enum import Enum
from pydantic import BaseModel, Field, ConfigDict
from mcp.server.fastmcp import FastMCP

# ---------------------------------------------------------------------------
# Configuration
# ---------------------------------------------------------------------------

API_TOKEN = os.environ.get("PIPEDRIVE_API_TOKEN", "")
COMPANY_DOMAIN = os.environ.get("PIPEDRIVE_DOMAIN", "")
BASE_URL = f"https://{COMPANY_DOMAIN}.pipedrive.com/api/v2"
BASE_URL_V1 = f"https://{COMPANY_DOMAIN}.pipedrive.com/api/v1"
DEFAULT_LIMIT = 20
REQUEST_TIMEOUT = 30

mcp = FastMCP("pipedrive_mcp")

# ---------------------------------------------------------------------------
# Shared helpers
# ---------------------------------------------------------------------------

def _headers() -> dict:
    return {
        "x-api-token": API_TOKEN,
        "Content-Type": "application/json",
        "Accept": "application/json",
    }


async def _get(path: str, params: dict | None = None, version: str = "v2") -> dict:
    """GET request to Pipedrive API."""
    base = BASE_URL if version == "v2" else BASE_URL_V1
    url = f"{base}/{path}"
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        resp = await client.get(url, headers=_headers(), params=params or {})
        resp.raise_for_status()
        return resp.json()


async def _post(path: str, body: dict, version: str = "v2") -> dict:
    """POST request to Pipedrive API."""
    base = BASE_URL if version == "v2" else BASE_URL_V1
    url = f"{base}/{path}"
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        resp = await client.post(url, headers=_headers(), json=body)
        resp.raise_for_status()
        return resp.json()


async def _put(path: str, body: dict, version: str = "v2") -> dict:
    """PUT request to Pipedrive API."""
    base = BASE_URL if version == "v2" else BASE_URL_V1
    url = f"{base}/{path}"
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        resp = await client.put(url, headers=_headers(), json=body)
        resp.raise_for_status()
        return resp.json()


async def _patch(path: str, body: dict, version: str = "v2") -> dict:
    """PATCH request to Pipedrive API."""
    base = BASE_URL if version == "v2" else BASE_URL_V1
    url = f"{base}/{path}"
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        resp = await client.patch(url, headers=_headers(), json=body)
        resp.raise_for_status()
        return resp.json()


async def _delete(path: str, version: str = "v2") -> dict:
    """DELETE request to Pipedrive API."""
    base = BASE_URL if version == "v2" else BASE_URL_V1
    url = f"{base}/{path}"
    async with httpx.AsyncClient(timeout=REQUEST_TIMEOUT) as client:
        resp = await client.delete(url, headers=_headers())
        resp.raise_for_status()
        return resp.json()


def _handle_error(e: Exception) -> str:
    if isinstance(e, httpx.HTTPStatusError):
        status = e.response.status_code
        try:
            detail = e.response.json()
        except Exception:
            detail = e.response.text
        if status == 401:
            return f"Error 401: Invalid API token. Check PIPEDRIVE_API_TOKEN. Detail: {detail}"
        if status == 403:
            return f"Error 403: Permission denied. Your token may not have access to this resource."
        if status == 404:
            return f"Error 404: Resource not found. Check the ID you provided."
        if status == 429:
            return f"Error 429: Rate limit exceeded. Wait a moment and try again."
        return f"Error {status}: {detail}"
    if isinstance(e, httpx.TimeoutException):
        return "Error: Request timed out. Try again."
    return f"Error: {type(e).__name__}: {e}"


def _fmt(data: Any) -> str:
    """Format API response as readable JSON."""
    return json.dumps(data, indent=2, default=str)


# ---------------------------------------------------------------------------
# Audit logging
# ---------------------------------------------------------------------------
# Every mutating action (merge, delete, link, owner-change) is appended to a
# local CSV so there is a durable, recoverable trace of what changed and when.
# Location: alongside this server file, or override with PIPEDRIVE_AUDIT_LOG.

import csv
from datetime import datetime, timezone

_AUDIT_PATH = os.environ.get(
    "PIPEDRIVE_AUDIT_LOG",
    os.path.join(os.path.dirname(os.path.abspath(__file__)), "audit-log.csv"),
)
_AUDIT_HEADER = ["timestamp_utc", "action", "entity_type", "kept_or_target_id", "affected_or_deleted_id", "detail"]


def _audit(action: str, entity_type: str, kept_or_target_id: Any, affected_or_deleted_id: Any, detail: str = "") -> None:
    """Append one row to the audit CSV. Best-effort: never breaks the tool call if logging fails."""
    try:
        new_file = not os.path.exists(_AUDIT_PATH)
        with open(_AUDIT_PATH, "a", newline="", encoding="utf-8") as fh:
            w = csv.writer(fh)
            if new_file:
                w.writerow(_AUDIT_HEADER)
            w.writerow([
                datetime.now(timezone.utc).isoformat(),
                action, entity_type,
                kept_or_target_id, affected_or_deleted_id,
                detail,
            ])
    except Exception:
        pass  # logging must never block the operation

class PipedriveSearchDealsInput(BaseModel):
    """Search deals by term."""
    model_config = ConfigDict(str_strip_whitespace=True, extra="forbid")
    term: str = Field(..., description="Search term to look for in deal titles", min_length=1)
    limit: Optional[int] = Field(default=DEFAULT_LIMIT, description="Max results (1-100)", ge=1, le=100)


@mcp.tool(
    name="pipedrive_search_deals",
    annotations={"readOnlyHint": True, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_search_deals(params: PipedriveSearchDealsInput) -> str:
    """Search for deals in Pipedrive by title/keyword. Returns matching deals with their value, stage, and status."""
    try:
        data = await _get("deals/search", {"term": params.term, "limit": params.limit}, version="v1")
        items = data.get("data", {}).get("items", [])
        if not items:
            return f"No deals found matching '{params.term}'."
        results = []
        for item in items:
            d = item.get("item", {})
            results.append({
                "id": d.get("id"),
                "title": d.get("title"),
                "value": d.get("value"),
                "currency": d.get("currency"),
                "status": d.get("status"),
                "stage": d.get("stage", {}).get("name") if isinstance(d.get("stage"), dict) else d.get("stage_id"),
                "person": d.get("person", {}).get("name") if isinstance(d.get("person"), dict) else None,
                "organization": d.get("organization", {}).get("name") if isinstance(d.get("organization"), dict) else None,
            })
        return _fmt({"count": len(results), "deals": results})
    except Exception as e:
        return _handle_error(e)


class PipedriveListDealsInput(BaseModel):
    """List deals with optional filters."""
    model_config = ConfigDict(str_strip_whitespace=True, extra="forbid")
    status: Optional[str] = Field(default=None, description="Filter by status: open, won, lost, deleted")
    limit: Optional[int] = Field(default=DEFAULT_LIMIT, ge=1, le=100)
    cursor: Optional[str] = Field(default=None, description="Pagination cursor from previous response")


@mcp.tool(
    name="pipedrive_list_deals",
    annotations={"readOnlyHint": True, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_list_deals(params: PipedriveListDealsInput) -> str:
    """List deals from Pipedrive with optional status filter. Returns deal details including value, stage, and contacts."""
    try:
        p: dict = {"limit": params.limit}
        if params.status:
            p["status"] = params.status
        if params.cursor:
            p["cursor"] = params.cursor
        data = await _get("deals", p)
        deals = data.get("data", [])
        cursor = data.get("additional_data", {}).get("next_cursor")
        return _fmt({"count": len(deals), "next_cursor": cursor, "deals": deals})
    except Exception as e:
        return _handle_error(e)


class PipedriveGetDealInput(BaseModel):
    """Get a single deal by ID."""
    model_config = ConfigDict(extra="forbid")
    deal_id: int = Field(..., description="The Pipedrive deal ID", ge=1)


@mcp.tool(
    name="pipedrive_get_deal",
    annotations={"readOnlyHint": True, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_get_deal(params: PipedriveGetDealInput) -> str:
    """Get full details of a single deal by its ID, including all custom fields."""
    try:
        data = await _get(f"deals/{params.deal_id}")

    except Exception as e:
        return _handle_error(e)

    annotations={"readOnlyHint": False, "destructiveHint": True, "idempotentHint": False, "openWorldHint": False},
)
async def pipedrive_delete(params: PipedriveDeleteInput) -> str:
    """Delete an entity (deal, person, organization, activity, or note) from Pipedrive. This is destructive; records are recoverable for ~30 days. Set dry_run=true to preview. Every real delete is written to the audit log."""
    try:
        entity_map = {
            "deal": "deals",
            "person": "persons",
            "organization": "organizations",
            "activity": "activities",
            "note": "notes",
        }
        et = params.entity_type.lower()
        path_prefix = entity_map.get(et)
        if not path_prefix:
            return f"Error: Unknown entity type '{params.entity_type}'. Must be one of: deal, person, organization, activity, note."
        if params.dry_run:
            return _fmt({
                "dry_run": True,
                "would_delete": et,
                "id": params.entity_id,
                "note": "No changes made. Re-call with dry_run=false to execute.",
            })
        version = "v1" if et in ("activity", "note") else "v2"
        await _delete(f"{path_prefix}/{params.entity_id}", version=version)
        _audit("delete", et, "", params.entity_id, "")
        return f"Successfully deleted {params.entity_type} #{params.entity_id}. (logged)"
    except Exception as e:
        return _handle_error(e)

# Simple in-process cache so we don't refetch field schemas on every call.
_FIELD_CACHE: Dict[str, list] = {}


async def _fetch_fields(entity: str) -> list:
    """Fetch and cache custom+default field definitions for deal/person/organization."""
    if entity in _FIELD_CACHE:
        return _FIELD_CACHE[entity]
    endpoint = {
        "deal": "dealFields",
        "person": "personFields",
        "organization": "organizationFields",
    }[entity]
    fields = []
    more = True
    start = 0
    while more:
        data = await _get(endpoint, {"start": start, "limit": 100}, version="v1")
        fields.extend(data.get("data", []) or [])
        pag = data.get("additional_data", {}).get("pagination", {})
        more = pag.get("more_items_in_collection", False)
        start = pag.get("next_start", 0) or 0
        if not more:
            break
    _FIELD_CACHE[entity] = fields
    return fields

        "Matching strictness. 'pipedrive' mirrors Pipedrive's own rules: persons match on same name + "
        "(same email OR same phone OR same org); orgs match on same name + same address. "
        "'strict' requires an exact shared email (persons) or exact name+address (orgs). "
        "'name_only' groups purely by normalized name (loosest, most false positives)."
    ))


def _norm(s: Any) -> str:
    # Coerce anything non-string to a safe string first. v2 can return structured
    # values (e.g. address as a dict, or email/phone entries as dicts); guard them all.
    if s is None:
        return ""
    if isinstance(s, dict):
        # Prefer a human-readable subfield if present, else stringify the whole thing.
        s = s.get("value") or s.get("formatted_address") or s.get("name") or ""
        if isinstance(s, dict):
            s = ""
    if not isinstance(s, str):
        s = str(s)
    return "".join(ch for ch in s.lower().strip() if ch.isalnum())


def _completeness_score(r: dict) -> int:
    """Rough richness score so we can suggest which record to KEEP (higher = keep)."""
    score = 0
    for key in ("emails", "phones", "label_ids"):
        v = r.get(key)
        if v:
            score += len(v) if isinstance(v, list) else 1
    if r.get("org_id"):
        score += 1
    if r.get("address"):
        score += 1
    # counts if present in payload
    for c in ("open_deals_count", "closed_deals_count", "activities_count", "done_activities_count", "notes_count", "people_count"):
        try:
            score += int(r.get(c) or 0)
        except (TypeError, ValueError):
            pass
    return score


async def _paginate(path: str, max_records: int) -> list:
    """Pull up to max_records records, following v2 cursor pagination in pages of 500."""
    out: list = []
    cursor = None
    while len(out) < max_records:
        page_limit = min(500, max_records - len(out))
        params = {"limit": page_limit}
        if cursor:
            params["cursor"] = cursor
        data = await _get(path, params)
        batch = data.get("data", []) or []
        out.extend(batch)
        cursor = data.get("additional_data", {}).get("next_cursor")
        if not cursor or not batch:
            break
    return out

async def pipedrive_find_duplicates(params: PipedriveFindDuplicatesInput) -> str:
    """Detect duplicate persons or organizations across the whole book (paginated), using Pipedrive's own matching logic by default. Returns ready-to-act duplicate groups: each group includes a suggested keep_id (the richest/oldest record) and merge_ids (the others), so a routine can hand them straight to pipedrive_merge_persons / pipedrive_merge_organizations. Read-only: it never merges anything itself."""
    try:
        entity = params.entity_type.lower()
        if entity not in ("person", "organization"):
            return "Error: entity_type must be person or organization."
        mode = (params.match_mode or "pipedrive").lower()
        if mode not in ("pipedrive", "strict", "name_only"):
            return "Error: match_mode must be pipedrive, strict, or name_only."
        path = "persons" if entity == "person" else "organizations"
        records = await _paginate(path, params.max_records)

        # Build a composite signature for each record based on entity + mode.
        # Records sharing any signature are grouped as duplicates.
        # We map signature -> set of record ids, then coalesce ids that co-occur.
        from collections import defaultdict

        sig_to_ids: Dict[str, set] = defaultdict(set)
        rec_by_id: Dict[int, dict] = {}

        for r in records:
            rid = r.get("id")
            if rid is None:
                continue
            rec_by_id[rid] = r
            name_key = _norm(r.get("name", ""))
            if not name_key:
                continue

            if entity == "person":
                emails = [(_norm(e.get("value")) if isinstance(e, dict) else _norm(e)) for e in (r.get("emails") or [])]
                emails = [e for e in emails if e]
                phones = [(_norm(p.get("value")) if isinstance(p, dict) else _norm(p)) for p in (r.get("phones") or [])]
                phones = [p for p in phones if p]
                org = r.get("org_id")
                org_id = org.get("value") if isinstance(org, dict) else org

                if mode == "name_only":
                    sig_to_ids[f"n:{name_key}"].add(rid)
                elif mode == "strict":
                    for e in emails:
                        sig_to_ids[f"e:{e}"].add(rid)
                else:  # pipedrive rules: name + (email | phone | org)
                    for e in emails:
                        sig_to_ids[f"ne:{name_key}|{e}"].add(rid)
                    for p in phones:
                        sig_to_ids[f"np:{name_key}|{p}"].add(rid)
                    if org_id:
                        sig_to_ids[f"no:{name_key}|{org_id}"].add(rid)
            else:  # organization
                addr = _norm(r.get("address", ""))
                if mode == "name_only":
                    sig_to_ids[f"n:{name_key}"].add(rid)
                else:  # both 'pipedrive' and 'strict' for orgs: name + address
                    if addr:
                        sig_to_ids[f"na:{name_key}|{addr}"].add(rid)
                    elif mode == "pipedrive":
                        # pipedrive flags same-name orgs even without address as weaker candidates
                        sig_to_ids[f"n:{name_key}"].add(rid)

        # Coalesce: union any id-sets that overlap (a record can share different sigs with different peers)
        groups: List[set] = []
        for ids in sig_to_ids.values():
            if len(ids) < 2:
                continue
            placed = False
            for g in groups:
                if g & ids:
                    g |= ids
                    placed = True
                    break
            if not placed:
                groups.append(set(ids))
        # second pass to merge any groups that now overlap
        merged = True
        while merged:
            merged = False
            for i in range(len(groups)):
                for j in range(i + 1, len(groups)):
                    if groups[i] & groups[j]:
                        groups[i] |= groups[j]
                        groups.pop(j)
                        merged = True
                        break
                if merged:
                    break

        # Build routine-ready output with a suggested keep_id per group
        results = []
        for g in groups:
            members = [rec_by_id[i] for i in g if i in rec_by_id]
            if len(members) < 2:
                continue
            # keep the richest; tie-break to the oldest (smallest id)
            members_sorted = sorted(members, key=lambda r: (-_completeness_score(r), r.get("id")))
            keep = members_sorted[0]
            merge_ids = [m.get("id") for m in members_sorted[1:]]
            results.append({
                "name": keep.get("name"),
                "keep_id": keep.get("id"),
                "merge_ids": merge_ids,
                "members": [{
                    "id": m.get("id"),
                    "name": m.get("name"),
                    "emails": [e.get("value") if isinstance(e, dict) else e for e in (m.get("emails") or [])],
                    "org_id": (m.get("org_id", {}).get("value") if isinstance(m.get("org_id"), dict) else m.get("org_id")),
                    "richness": _completeness_score(m),
                } for m in members_sorted],
            })

        # Largest groups first so a routine can tackle the messiest records early
        results.sort(key=lambda x: len(x["merge_ids"]), reverse=True)

        return _fmt({
            "entity": entity,
            "match_mode": mode,
            "scanned": len(records),
            "duplicate_group_count": len(results),
            "total_records_mergeable": sum(len(r["merge_ids"]) for r in results),
            "groups": results,
            "how_to_use": (
                f"For each group, call pipedrive_merge_{'persons' if entity=='person' else 'organizations'} "
                f"once per id in merge_ids, passing that id as the merge-FROM and keep_id as merge_with_id. "
                "keep_id is the richest record (most deals/activities/contacts); it survives. Merges are irreversible."
            ),
        })
    except Exception as e:
        return _handle_error(e)


# ===========================================================================
# COMPREHENSIVE RAW WRITE LAYER
# ===========================================================================
# These tools write ANY field (standard or custom) on deals, persons, orgs.
# They handle the Pipedrive v2 format rules so Claude does not send bad payloads:
#   - custom fields (40-char hash keys) are auto-wrapped in a "custom_fields" object
#   - label_ids must be an array of ints
#   - visible_to must be an int
#   - multi-option (set) fields take an array of option IDs; use null (not []) to clear
#
# STANDARD_KEYS lists the top-level standard fields each entity accepts on PATCH/POST.
# Anything not in this list AND 40 chars long is treated as a custom field.

STANDARD_KEYS = {
    "deal": {
        "title", "value", "currency", "user_id", "owner_id", "person_id", "org_id",
        "pipeline_id", "stage_id", "status", "expected_close_date", "probability",
        "lost_reason", "visible_to", "add_time", "won_time", "lost_time", "close_time",
        "label_ids", "creator_user_id",
    },
    "person": {
        "name", "owner_id", "org_id", "emails", "phones", "visible_to", "label_ids",
        "marketing_status", "add_time",
    },
    "organization": {
        "name", "owner_id", "address", "visible_to", "label_ids", "add_time",
    },
}

_PATH_MAP = {"deal": "deals", "person": "persons", "organization": "organizations"}


def _split_fields(entity: str, fields: dict) -> dict:
    """Separate standard top-level fields from custom (hash) fields and build a v2 body.

    - Standard keys stay top-level.
    - 40-char keys go inside custom_fields.
    - label_ids and visible_to are coerced to the correct types.
    """
    body: Dict[str, Any] = {}
    custom: Dict[str, Any] = {}
    std = STANDARD_KEYS.get(entity, set())
    for k, v in fields.items():
        if len(k) == 40 and k not in std:
            custom[k] = v
        else:
            # Type coercions for known-fussy standard fields
            if k == "label_ids" and v is not None:
                if isinstance(v, list):
                    body[k] = [int(x) for x in v]
                else:
                    body[k] = [int(x) for x in str(v).split(",") if str(x).strip()]
            elif k == "visible_to" and v is not None:
                body[k] = int(v)
            else:
                body[k] = v
    if custom:
        body["custom_fields"] = custom
    return body

async def pipedrive_batch_update(params: PipedriveBatchUpdateInput) -> str:
    """Comprehensive batch write: update many deals/persons/orgs in one call, each with any standard or custom fields. Pass a JSON array of {id, fields} objects. Runs sequentially, continues past individual failures, and returns a per-record report. Set dry_run=true to preview the resolved payloads without writing.     try:
        entity = params.entity_type.lower()

            return "Error: entity_type must be deal, person, or organization."
        try:
            updates = json.loads(params.updates_json)
        except json.JSONDecodeError as je:
            return f"Error: updates_json is not valid JSON. {je}"
        if not isinstance(updates, list) or not updates:
            return "Error: updates_json must be a non-empty JSON array."

        if params.dry_run:
            preview = []
            for i, item in enumerate(updates):
                if not isinstance(item, dict) or "id" not in item or "fields" not in item:
                    preview.append({"index": i, "error": "each item needs 'id' and 'fields'"})

            return _fmt({
                "dry_run": True,
                "entity": entity,
                "total": len(updates),
                "preview": preview,
                "note": "No changes made. Re-call with dry_run=false to execute.",
            })

        succeeded, failed = [], []
        for i, item in enumerate(updates):
            if not isinstance(item, dict) or "id" not in item or "fields" not in item:

                continue

                failed.append({"id": item.get("id"), "error": _handle_error(ie)})

            "entity": entity,
            "total": len(updates),
            "succeeded_count": len(succeeded),
            "failed_count": len(failed),
            "succeeded_ids": succeeded,
            "failed": failed,
            "logged": True,
        })
    except Exception as e:
        return _handle_error(e)

# MAIL THREADS (link email conversations to deals)
# ===========================================================================
# Pipedrive stores email conversations as "mail threads". A thread can be linked
# to exactly ONE item (deal, lead, or project). These tools let a routine find
# unlinked threads and attach them to the right deal.
#
# Matching strategy (chosen): exact recipient email -> person -> that person's deal.
# Endpoints (all v1):
#   GET  /mailbox/mailThreads?folder={inbox|sent|drafts|archive}
#   GET  /mailbox/mailThreads/{id}/mailMessages   (to read participant emails)
#   PUT  /mailbox/mailThreads/{id}   body {deal_id: N}   (reversible; relink anytime)

_MAIL_FOLDERS = ["inbox", "sent", "drafts", "archive"]


async def _thread_participant_emails(thread_id: int) -> list:
    """Return the distinct non-account email addresses seen in a thread's messages."""
    try:
        data = await _get(f"mailbox/mailThreads/{thread_id}/mailMessages", {"include_body": 0}, version="v1")
    except Exception:
        return []
    msgs = data.get("data", []) or []
    emails: list = []
    for m in msgs:
        for field in ("from", "to", "cc"):
            parties = m.get(field) or []
            if isinstance(parties, list):
                for p in parties:
                    val = (p.get("email_address") if isinstance(p, dict) else None) or ""
                    val = val.lower().strip()
                    if val and val not in emails:
                        emails.append(val)
    return emails

    model_config = ConfigDict(str_strip_whitespace=True, extra="forbid")
    folder: Optional[str] = Field(default="all", description="Folder to scan: inbox, sent, drafts, archive, or 'all' for every folder")
    unlinked_only: Optional[bool] = Field(default=True, description="Return only threads not yet linked to a deal/lead")
    scan_depth_per_folder: Optional[int] = Field(default=2000, description="How many threads to SCAN per folder (paginated in pages of 200). This is the search depth, NOT the number returned. Raise it if a folder is mostly already-linked and the unlinked backlog is older/deeper.", ge=1, le=20000)
    max_unlinked: Optional[int] = Field(default=200, description="Stop scanning a folder once this many matching (unlinked) threads have been collected. Caps the result size independently of scan depth.", ge=1, le=5000)


@mcp.tool(
    name="pipedrive_list_mail_threads",
    annotations={"readOnlyHint": True, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_list_mail_threads(params: PipedriveListMailThreadsInput) -> str:
    """List email threads across mail folders, defaulting to only those NOT yet linked to a deal. Returns thread id, subject, current deal_id (null if unlinked), participant count, and last-message time. Use this to find email conversations that still need to be attached to a deal, then pass each to pipedrive_link_mail_thread_to_deal."""
    try:
        folders = _MAIL_FOLDERS if (params.folder or "all").lower() == "all" else [params.folder.lower()]
        for f in folders:
            if f not in _MAIL_FOLDERS:
                return f"Error: folder must be one of {_MAIL_FOLDERS} or 'all'."

        all_threads = []
        folder_stats = {}
        for folder in folders:
            start = 0
            scanned = 0
            collected = 0
            while scanned < params.scan_depth_per_folder and collected < params.max_unlinked:
                page = min(200, params.scan_depth_per_folder - scanned)
                data = await _get("mailbox/mailThreads", {"folder": folder, "start": start, "limit": page}, version="v1")
                batch = data.get("data", []) or []
                if not batch:
                    break
                scanned += len(batch)
                for t in batch:
                    deal_id = t.get("deal_id")
                    lead_id = t.get("lead_id")
                    if params.unlinked_only and (deal_id or lead_id):
                        continue
                    all_threads.append({
                        "thread_id": t.get("id"),
                        "folder": folder,
                        "subject": t.get("subject"),
                        "deal_id": deal_id,
                        "lead_id": lead_id,
                        "message_count": t.get("message_count"),
                        "parties_count": t.get("parties_count") or (len(t.get("parties", {}).get("to", [])) if isinstance(t.get("parties"), dict) else None),
                        "last_message_timestamp": t.get("last_message_timestamp"),
                        "snippet": t.get("snippet"),
                    })
                    collected += 1
                    if collected >= params.max_unlinked:
                        break
                pag = data.get("additional_data", {}).get("pagination", {})
                if not pag.get("more_items_in_collection"):
                    break
                start = pag.get("next_start", start + page)
            folder_stats[folder] = {"scanned": scanned, "matched": collected, "hit_scan_limit": scanned >= params.scan_depth_per_folder}

        # Warn if any folder was capped by scan depth while still finding matches - backlog may be deeper
        capped = [f for f, st in folder_stats.items() if st["hit_scan_limit"]]
        return _fmt({
            "folders_scanned": folders,
            "unlinked_only": params.unlinked_only,
            "count": len(all_threads),
            "per_folder": folder_stats,
            "scan_depth_note": (
                f"Folders that hit the scan-depth cap: {capped}. Raise scan_depth_per_folder to look deeper for older unlinked threads."
                if capped else "Full folders scanned; no scan-depth cap was hit."
            ),
            "threads": all_threads,
            "next_step": "For each thread, call pipedrive_link_mail_thread_to_deal with the thread_id; it matches the thread's recipient email to a person and links their deal.",
        })
    except Exception as e:
        return _handle_error(e)

@mcp.tool(
    name="pipedrive_link_mail_thread_to_deal",
    annotations={"readOnlyHint": False, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_link_mail_thread_to_deal(params: PipedriveLinkMailThreadInput) -> str:
    """Link an email thread to a deal. If deal_id is given, links directly. If omitted, auto-matches: reads the thread's participant emails, finds the matching person by exact email, and links the thread to that person's open deal (only when the match is unambiguous). Reversible: call again with a different deal_id to relink. Note: a thread can be linked to only one item."""
    try:
        resolved_deal_id = params.deal_id
        match_note = "explicit deal_id provided"

        if resolved_deal_id is None:
            # Auto-match: participant email -> person (exact) -> their deal
            emails = await _thread_participant_emails(params.thread_id)
            # Drop obvious internal/account addresses so we match the external party
            external = [e for e in emails if "pipedrivemail.com" not in e]
            candidate_persons = []
            for em in external:
                pdata = await _get("persons/search", {"term": em, "fields": "email", "exact_match": 1, "limit": 5}, version="v1")
                items = pdata.get("data", {}).get("items", []) or []
                for it in items:
                    person = it.get("item", {})
                    if person.get("id") and person["id"] not in [c["id"] for c in candidate_persons]:
                        candidate_persons.append({"id": person["id"], "name": person.get("name"), "email": em})

            if not candidate_persons:
                return _fmt({"status": "skipped", "reason": "no person matched any participant email exactly", "thread_id": params.thread_id, "emails_checked": external})

            # Collect open deals across matched persons
            deals_found = []
            for cp in candidate_persons:
                ddata = await _get("deals", {"person_id": cp["id"], "status": "open", "limit": 10})
                for d in (ddata.get("data", []) or []):
                    deals_found.append({"deal_id": d.get("id"), "title": d.get("title"), "person_id": cp["id"], "person": cp["name"]})

            if len(deals_found) == 0:
                return _fmt({"status": "skipped", "reason": "matched a person but they have no open deal to link", "thread_id": params.thread_id, "matched_persons": candidate_persons})
            if len(deals_found) > 1:
                return _fmt({"status": "ambiguous", "reason": "more than one open deal matched; not auto-linking. Re-call with an explicit deal_id.", "thread_id": params.thread_id, "candidate_deals": deals_found})

            resolved_deal_id = deals_found[0]["deal_id"]

        return _fmt({
            "status": "linked",
            "thread_id": params.thread_id,
            "deal_id": resolved_deal_id,
            "match": match_note,
            "reversible": "Yes. Call again with a different deal_id to relink.",
        })

async def _product_default_price(product_id: int) -> float:
    """Fetch a product and return its default (first) catalog price, or 0 if none set."""
    try:
        data = await _get(f"products/{product_id}", version="v1")
        prices = (data.get("data", {}) or {}).get("prices", []) or []
        if prices and isinstance(prices, list):
            return float(prices[0].get("price", 0) or 0)
    except Exception:
        pass
    return 0.0


@mcp.tool(
    name="pipedrive_tag_deal_modules",
    annotations={"readOnlyHint": False, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_tag_deal_modules(params: PipedriveTagDealModulesInput) -> str:
    """Tag a deal with Osmos modules by name (e.g. ["Onsite","Instore"]). Resolves each module name to its catalog product via exact-name search, attaches it to the deal at the product's default catalog price, quantity 1. Set replace_existing=true to clear current products first. Set dry_run=true to see the resolved plan without writing. Built for module-mapper output to flow straight onto the deal."""
    try:
        # Resolve each module name to a product_id (exact match)
        resolved, unresolved = [], []
        for name in params.module_names:
            sdata = await _get("products/search", {"term": name, "exact_match": 1, "limit": 5}, version="v1")
            items = sdata.get("data", {}).get("items", []) or []
            match = None
            for it in items:
                p = it.get("item", {})
                if (p.get("name") or "").strip().lower() == name.strip().lower():
                    match = p
                    break
            if match is None and items:
                match = items[0].get("item", {})  # fall back to top hit
            if match and match.get("id"):
                price = await _product_default_price(match["id"])
                resolved.append({"module": name, "product_id": match["id"], "product_name": match.get("name"), "price": price})
            else:
                unresolved.append(name)

        if params.dry_run:
            return _fmt({
                "dry_run": True,
                "deal_id": params.deal_id,
                "replace_existing": params.replace_existing,
                "would_attach": resolved,
                "unresolved_names": unresolved,
                "note": "No changes made. Re-call with dry_run=false to execute.",
            })

        if unresolved:
            return _fmt({
                "status": "aborted",
                "reason": "some module names did not resolve to a product; nothing was changed",
                "unresolved_names": unresolved,
                "resolved": resolved,
                "hint": "Check the exact product names in your catalog, or create the missing module products first.",
            })

        removed = []
        if params.replace_existing:
            existing = await _get(f"deals/{params.deal_id}/products", {"include_product_data": 0}, version="v1")
            for p in (existing.get("data", []) or []):
                try:
                    await _delete(f"deals/{params.deal_id}/products/{p.get('id')}", version="v1")
                    removed.append(p.get("id"))
                except Exception:
                    pass

        attached = []
        for r in resolved:
            body = {"product_id": r["product_id"], "item_price": r["price"], "quantity": 1}
            data = await _post(f"deals/{params.deal_id}/products", body, version="v1")
            attached.append({"module": r["module"], "product_id": r["product_id"], "attachment_id": data.get("data", {}).get("id")})

        _audit("tag_modules", "deal", params.deal_id, "", f"modules={','.join(m['module'] for m in resolved)}; replaced={len(removed)}")
        return _fmt({
            "status": "tagged",
            "deal_id": params.deal_id,
            "attached": attached,
            "removed_attachments": removed if params.replace_existing else "n/a (add mode)",
            "logged": True,
        })
    except Exception as e:
        return _handle_error(e)


# ===========================================================================
# BATCH MAIL-THREAD LINKING (process the unlinked backlog in chunks)
# ===========================================================================

async def _match_thread_to_deal(thread_id: int, ambiguous_tiebreak: bool) -> dict:
    """Resolve one thread to a deal via exact participant email -> person -> open deal.
    Returns a dict describing the outcome without performing the link.
    ambiguous_tiebreak: if True, when multiple open deals match, pick the most recently updated one.
    """
    emails = await _thread_participant_emails(thread_id)
    external = [e for e in emails if "pipedrivemail.com" not in e]
    persons = []
    for em in external:
        pdata = await _get("persons/search", {"term": em, "fields": "email", "exact_match": 1, "limit": 5}, version="v1")
        for it in (pdata.get("data", {}).get("items", []) or []):
            p = it.get("item", {})
            if p.get("id") and p["id"] not in [c["id"] for c in persons]:
                persons.append({"id": p["id"], "name": p.get("name"), "email": em})

    if not persons:
        return {"thread_id": thread_id, "outcome": "skipped", "reason": "no person matched participant emails", "emails": external}

    deals = []
    for cp in persons:
        ddata = await _get("deals", {"person_id": cp["id"], "status": "open", "limit": 20})
        for d in (ddata.get("data", []) or []):
            deals.append({"deal_id": d.get("id"), "title": d.get("title"), "update_time": d.get("update_time"), "person": cp["name"]})

    if len(deals) == 0:
        return {"thread_id": thread_id, "outcome": "skipped", "reason": "matched person has no open deal", "persons": persons}
    if len(deals) == 1:
        return {"thread_id": thread_id, "outcome": "match", "deal_id": deals[0]["deal_id"], "basis": "unambiguous", "detail": f"{deals[0]['person']} -> {deals[0]['title']}"}
    # multiple deals
    if not ambiguous_tiebreak:
        return {"thread_id": thread_id, "outcome": "ambiguous", "candidate_deals": deals}
    # tie-break: most recently updated open deal
    chosen = sorted(deals, key=lambda d: (d.get("update_time") or ""), reverse=True)[0]
    return {"thread_id": thread_id, "outcome": "match", "deal_id": chosen["deal_id"], "basis": "tiebreak_most_recent", "detail": f"{chosen['person']} -> {chosen['title']} (chosen from {len(deals)} open deals by most recent update)"}


class PipedriveBatchLinkMailThreadsInput(BaseModel):
    model_config = ConfigDict(str_strip_whitespace=True, extra="forbid")
    folder: Optional[str] = Field(default="sent", description="Folder to process: inbox, sent, drafts, or archive (one folder per batch)")
    batch_size: Optional[int] = Field(default=100, description="How many unlinked threads to process in this call", ge=1, le=200)
    start: Optional[int] = Field(default=0, description="Pagination start offset into the folder. Use the returned next_start to resume the next batch.")
    ambiguous_tiebreak: Optional[bool] = Field(default=True, description="When a thread's contact has more than one open deal, link to the most recently updated one. If false, such threads are reported as 'ambiguous' and left unlinked.")
    dry_run: Optional[bool] = Field(default=False, description="If true, resolve and report what each thread WOULD link to, but link nothing.")


@mcp.tool(
    name="pipedrive_batch_link_mail_threads",
    annotations={"readOnlyHint": False, "destructiveHint": False, "idempotentHint": True, "openWorldHint": False},
)
async def pipedrive_batch_link_mail_threads(params: PipedriveBatchLinkMailThreadsInput) -> str:
    """Process a folder's unlinked email threads in one batch: for each, auto-match via exact participant email -> person -> open deal, and link it. Unambiguous matches (one open deal) link directly; when a contact has multiple open deals, the most recently updated one is chosen if ambiguous_tiebreak is on, otherwise reported and skipped. Returns a per-thread report (linked / skipped / ambiguous), counts, and a next_start cursor to resume the next batch. Set dry_run=true to preview without linking. Links are reversible. Every real link is written to the audit log."""
    try:
        folder = (params.folder or "sent").lower()
        if folder not in _MAIL_FOLDERS:
            return f"Error: folder must be one of {_MAIL_FOLDERS}."

        # Pull a page of threads and keep only unlinked ones, up to batch_size
        unlinked = []
        start = params.start
        scanned = 0
        while len(unlinked) < params.batch_size and scanned < 2000:
            page = min(200, 2000 - scanned)
            data = await _get("mailbox/mailThreads", {"folder": folder, "start": start, "limit": page}, version="v1")
            batch = data.get("data", []) or []
            if not batch:
                break
            scanned += len(batch)
            for t in batch:
                if not (t.get("deal_id") or t.get("lead_id")):
                    unlinked.append({"thread_id": t.get("id"), "subject": t.get("subject")})
                    if len(unlinked) >= params.batch_size:
                        break
            pag = data.get("additional_data", {}).get("pagination", {})
            next_start = pag.get("next_start", start + page)
            if not pag.get("more_items_in_collection"):
                start = next_start
                break
            start = next_start

        # Resolve (and optionally link) each
        linked, tiebroken, skipped, ambiguous = [], [], [], []
        for th in unlinked:
            res = await _match_thread_to_deal(th["thread_id"], params.ambiguous_tiebreak)
            res["subject"] = th["subject"]
            if res["outcome"] == "match":
                if not params.dry_run:
                    await _put(f"mailbox/mailThreads/{th['thread_id']}", {"deal_id": res["deal_id"]}, version="v1")
                    _audit("link_mail_thread", "deal", res["deal_id"], th["thread_id"], res.get("basis", ""))
                (tiebroken if res.get("basis") == "tiebreak_most_recent" else linked).append(res)
            elif res["outcome"] == "ambiguous":
                ambiguous.append(res)
            else:
                skipped.append(res)

        return _fmt({
            "dry_run": params.dry_run,
            "folder": folder,
            "processed": len(unlinked),
            "linked_unambiguous": len(linked),
            "linked_by_tiebreak": len(tiebroken),
            "skipped": len(skipped),
            "ambiguous_unlinked": len(ambiguous),
            "next_start": start,
            "resume_hint": f"Call again with start={start} to process the next {params.batch_size}.",
            "details": {
                "linked_unambiguous": linked,
                "linked_by_tiebreak": tiebroken,
                "skipped": skipped,
                "ambiguous_unlinked": ambiguous,
            },
        })
    except Exception as e:
        return _handle_error(e)

        _FIELD_CACHE.pop(entity, None)

            "status": "created",
            "entity": entity,
            "field_name": d.get("name"),
            "field_key": d.get("key"),
            "field_type": d.get("field_type"),

        entity = params.entity_type.lower()

        if not endpoint:
            return "Error: entity_type must be deal, person, or organization."
        body: Dict[str, Any] = {}
        if params.name:
            body["name"] = params.name
        if params.description is not None:
            body["description"] = params.description
        if params.add_options:
            body["options"] = [{"label": o} for o in params.add_options]
        if not body:
            return "Error: provide at least one of name, description, or add_options."

        data = await _patch(f"{endpoint}/{params.field_key}", body, version="v1")
        d = data.get("data", {}) or {}
        _FIELD_CACHE.pop(entity, None)
        _audit("update_field", entity, params.field_key, "", ",".join(body.keys()))
        return _fmt({
            "status": "updated",
            "entity": entity,
            "field_key": params.field_key,
            "changed": list(body.keys()),
            "name": d.get("name"),
            "description": d.get("description"),
            "logged": True,
        })
    except Exception as e:
        return _handle_error(e)
