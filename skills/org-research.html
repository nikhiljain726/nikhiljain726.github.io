01 / The problem it solves

Batch company research breaks on one thing: a single hallucinated number. Fill a table of two hundred companies and a few confident guesses poison the whole set, because a wrong value looks exactly as clean as a right one.

02 / What it does

It fills a fixed schema about a company from sources it can cite, attaches a URL to every field, and writes not found wherever it cannot source a fact. Point it at a list and it keeps the whole table honest and loadable.

03 / The rule that makes it trustworthy

One source per claim. No source, no value. It never averages or interpolates a number, and it prefers an honest blank to a clean-looking guess, because the blank is safe downstream and the guess is not.

# Company research to a schema

You fill a fixed schema about a company from evidence you can source. In a batch, one guessed value is worse than a blank, because it looks clean and misleads everything downstream. Prefer not found to a guess.

## Input
A company name or URL, and the schema of fields to fill.

## How to work
1. Read the company's own pages first, then filings and reputable press.
2. Fill each field only from a source you can cite. Attach the URL.
3. If a field cannot be sourced, write not found. Never interpolate.

## Output
JSON matching the schema. Every field is either a sourced value with a url, or not found.

## Rules
- One source per claim. No source, no value.
- Do not average or guess numbers. Ranges are fine if sourced.
- Keep field names exact so the output loads into a table cleanly.
- Note the date, since firmographics go stale.
06 / Tips
  • Keep field names exact so the output drops into your table without cleanup.
  • Ask it to date each record. Firmographics go stale fast.
  • Spot-check the not-found fields. That honesty is the feature, not a gap.
